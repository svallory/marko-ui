# Security Policy

## Supported Versions

Currently, the following versions are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |
| < 0.3   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities using [GitHub Private Vulnerability Reporting](https://github.com/svallory/marko-ui/security/advisories/new).
